# Security and privacy policy

## Supported use

This project is intended for transparent local diagnostics, browser compatibility testing, and privacy research. Do not use it for covert identification, cross-site tracking, fingerprint spoofing, stealth, identity rotation, or bypassing anti-bot / anti-fraud systems.

## Data handling

The application stores snapshots in the current browser's local storage and only exports data when the user presses the export button. Do not include personally identifying information in issue reports. Clearing browser site data removes locally stored snapshots.

## Reporting an issue

Please open a GitHub issue with:
- Browser name and version (if comfortable sharing)
- Operating system and relevant privacy settings
- Reproduction steps
- Expected and observed behavior
- A sanitized JSON report, only if it contains no sensitive information

Do not publish access tokens, private browsing data, or personal identifiers.
